## 검증하지 못한 부분

실행 환경의 브라우저 URL 접근 정책 때문에 실제 HTTP 서버 또는 file:// 페이지를 탐색하여 검증한 것은 아닙니다. CSS·JS를 모두 삽입한 동일 콘텐츠를 오프라인 렌더링했고, 실제 링크 파일의 존재와 경로를 정적으로 검사했습니다. 새 GitHub 저장소에서의 배포, DNS, HTTPS는 아직 수행하지 않았습니다.

실제 공개 세미나 Google Sheets 연결과 내용, 외부 논문/학교/지도 링크의 서버 응답은 이번 UI 검토에서 확인하지 않았습니다.

사진 원본 7개는 미포함입니다. 사진 없이 이니셜이 표시되는 상태만 확인했습니다. 사진을 복사한 뒤 실제 표시와 얼굴 크롭을 확인하세요. 실제 공식 대학 로고 역시 사용자가 넣은 뒤 확인해야 합니다.

미리보기 이미지는 Linux의 시스템 글꼴로 렌더링되었습니다. macOS/Windows는 각 OS의 system-ui 대체 글꼴을 사용하므로 글꼴 모양이 약간 다를 수 있습니다. 사용자 지정 폰트 파일은 포함하지 않았습니다.
